# Examples

## 概要
各サービスの使用例を提供するサンプルコードです。

## フォルダ構成
```
Examples/
├── AudioUsage/           # AudioService使用例
├── CustomizationUsage/   # CustomizationService使用例
├── InputUsage/           # InputService使用例
├── LobbyUsage/           # LobbyService使用例
├── MatchUsage/           # MatchService使用例
├── ReplayUsage/          # ReplayService使用例
├── SceneTransition/      # SceneManagementService使用例
└── SettingsUsage/        # GameSettingsService使用例
```

## 使い方
各フォルダ内のViewModelファイルを参照してください。
